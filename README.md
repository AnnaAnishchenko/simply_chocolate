# 🍫 Simply Chocolate

Simply Chocolate is a responsive promotional website created for a chocolate brand. The project showcases products, company values, customer reviews, and contact information through a modern and user-friendly interface.

🔗 **GitHub Repository:** https://github.com/AnnaAnishchenko/simply_chocolate

---

## 📖 About the Project

The project was developed as an individual frontend project to practice responsive web design, semantic HTML, modern CSS techniques, and interactive user interface implementation.

The website presents a fictional chocolate brand, highlighting its products, benefits, manufacturing process, and customer feedback.

---

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices

## 🚀 Getting Started

### Installation

Clone the repository:

```bash
git clone https://github.com/AnnaAnishchenko/simply_chocolate.git
```

Navigate to the project folder:

```bash
cd simply_chocolate
```

Open the project:

```bash
index.html
```

Or use Live Server in VS Code.
